# KooComic·可漫 for KOReader v0.4.2

KooComic·可漫由 Jackchen 独立开发和维护，依照 KOOBONE 提供的 API Key 接口方案连接用户个人漫画书库，让用户可以在 Kindle/KOReader 上浏览、下载并阅读自己的漫画。

> 用Koo可漫让你的KOOBONE漫画在Kindle上可以自在漫读。—— @Jackchen

本插件不是 KOOBONE 官方客户端。插件的界面、功能、发布与后续维护由本项目独立负责；KOOBONE 名称用于说明所连接的服务与接口来源。

## 主要功能

- 保留旧版设置和下载记录；首次使用新认证方式需要输入 KOOBONE API Key。
- API Key 保存在本机，用于获取和自动续期短期会话，无需向插件输入账号密码。
- 账号页面支持更换 API Key、清除旧版密码和退出账号。
- 书架提供继续阅读区、分层封面展示和统一的 Lucide 风格图标；竖屏默认 4 列 × 3 行，仍可分别设置竖屏/横屏的封面列数和行数及文字大小。
- 打开书会把封面裁切并铺满弧形纸面，不再出现矩形白底；阅读已下载漫画时，会在本机低分辨率缓存最近两张阅读画面，返回书架后作为左右书页显示。尚未积累两页或旧版 KOReader 不支持截图时自动回退到封面与标题页。
- “作品”视图会把同一系列的各卷合并成一张作品卡片，进入后按卷号查看全部漫画；长按“分类筛选”可自定义书架下方的快捷分类。
- 搜索、最近加入/标题/阅读进度排序，以及下载和阅读状态筛选。
- 封面、阅读进度与下载状态角标、上一页/下一页导航；长按页码箭头可到首页或末页。
- 底部书架、下载、账号、设置导航；不支持自定义网格的旧版 KOReader 自动回退到列表。
- HTTPS 封面按稳定书籍标识缓存在 KOReader 数据目录，失败时显示墨水屏占位封面。
- 书籍详情与下载状态。
- 流式写入 `.part`，显示下载百分比、大小、速度和预计剩余时间。
- 下载网络层遵循 KOReader 的统一 LuaSocket HTTPS 兼容路径，并保留底层超时或连接错误原因。
- 下载失败或取消后保留临时文件，避免产生伪装成完整 EPUB 的损坏文件。
- 下载管理按磁盘实际状态显示已完成、未完成或文件已删除；支持删除本地漫画、移除失效记录和清理 `.part` 临时文件。
- 下载目录可在设置中选择并验证是否可写；切换只影响新下载，旧目录漫画仍可识别、打开和删除。
- 新安装默认每天检查一次版本、每天最多提醒一次、三次“稍后更新”后停止自动提醒；下载和安装仍需用户确认。
- 更新说明可滚动阅读，底部更新按钮保持可见。
- 更新包大小与 SHA-256 校验、安全解压、旧版本备份和失败回滚。

## 安装

删除旧的插件代码目录（不要删除设置和漫画），再将整个 `koocomic.koplugin` 文件夹复制到：

```text
koreader/plugins/
```

完全重启 KOReader，然后打开：

```text
工具 → Koo可漫
```

## 在线更新

插件通过公开 GitHub Release 下载更新，并从 GitHub Pages 读取固定版本清单。当前地址配置在 `koobone/plugin_version.lua`：

```lua
manifest_url = "https://jackchensky.github.io/KooComic/update.json"
release_prefix = "https://github.com/jackchensky/KooComic/releases/download/"
```

自动检查只读取版本清单；下载和安装新版本前仍会要求用户确认，并校验文件大小和 SHA-256。

## 安全说明

- API Key 和短期会话保存在本机设置中，不要分享设置文件、密钥、Cookie、密码或未脱敏日志。
- 已保存的旧版密码不会在升级时自动删除，可在账号页面手动清除；备份文件可能仍包含旧数据。
- 退出账号会从当前设置清除 API Key、会话及旧版密码，不删除已下载漫画；如有旧设置备份，需单独妥善处理。
- 认证请求使用 HTTPS 并验证证书链与服务器域名；若设备缺少证书或验证能力，将拒绝连接。
- 封面缓存只包含公开书籍封面，不保存账号 Cookie 或签名下载地址。
- 阅读画面预览只保存在本机 KOReader 缓存中，每本最多两张低分辨率图片；删除漫画或移除失效下载记录时会一并清理，不上传到网络。
- 本版根据 KOOBONE 提供的接口说明开发，接口及不同 Kindle 的兼容性仍需真机验证。
