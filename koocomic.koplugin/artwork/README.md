# 打开书外观

KooComic 原创矢量素材，使用项目 AGPL-3.0-only 许可。

- `open-book-mono.svg`：黑白屏纸张、书脊和层叠页边。
- `open-book-warm.svg`：彩色屏暖纸色版本。
- 统一 400 × 280 画布。右内容安全区 `(226,43,130,179)`；左页封面按 `koobone/ui/book_surface.lua` 中的曲面映射，矩形 `(44,43,130,179)` 仅用于缺图占位。
- 仅使用路径、椭圆和线性渐变，无滤镜、外部资源、脚本、字体依赖或嵌入漫画。
- 外观与内容分层；目前左侧使用真实封面，右侧使用书名/卷号。不能把该组合称为实际漫画跨页截图。
- 两个素材共用几何形状，按设备尺寸等比例缩放。真实墨水屏透明度、渐变与对比度仍待真机确认。

## 曲面封面

- `book_surface.lua` 与 SVG 左页相同的上下二次曲线建立曲面，图片内容和边缘一起弯曲，并在书脊附近略微压缩、变暗；使用双线性采样和边缘透明度。
- `curved_cover.lua` 先把完整封面等比例缩到小缓冲区，再映射到纸面。不会修改原封面文件或影响下面书架封面。仅保留一个曲面结果缓存；每个正在显示的组件持有自己的副本，避免缓存替换导致失效引用。
- 解码或变形失败时保留底层书本图标，不在每次重绘时反复尝试。
- `scripts/render_book_surface_preview.cjs` 配合 `.lua` 调用插件同一算法生成桌面预览；需 Node.js 的 sharp 和 Lua 5.1（`KOOCOMIC_LUA_BIN`）。预览源来自此前原创示例封面，不含真实漫画或账号资料。
